# Public demonstration assets

Six screenshots of the actual native macOS interface and a two-page PDF, captured
on 15 October 2026 using an isolated development-only English meeting fixture.
All meeting text, dates, device metadata, names and voice samples are fictional.
The audio fixture is a generated tone, not a recording of a person. Text and
summaries are prepared examples, not inference output or quality benchmarks.

Screens show named transcript speakers, selecting saved profiles, a visual report,
PDF export, automatic synchronization/local processing settings, and the library.
The PDF was generated by Vecta's native visual-PDF writer and inspected for layout,
readable text and speaker names. No owner library, recording, model download,
inference worker or physical-device action was used. The installed app was not
launched or modified for these captures.

PNG pixel data is retained unchanged; ancillary metadata chunks were removed.
Only these exact image paths and the sample PDF are approved by the public-source
allowlist. Source/export checks are defense in depth, not proof that arbitrary
future image/PDF content is safe. Review any replacement visually before export.
The synthetic public-demo entrypoint exists only in development builds; production
verification rejects its marker in the application executable.
